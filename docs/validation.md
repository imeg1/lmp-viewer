# Статус проверки MVP 0.1

Дата: 19 октября 2026 года.

## Выполнено

- `npm run check` полностью прошёл: TypeScript, ESLint, Prettier,
  34 теста Vitest в четырёх файлах и сборка Vite.
- Создан `dist/plugin.js`: единственный артефакт, ES2015 IIFE,
  размер зависит от включённой диагностики; проверка структуры проходит.
- Финальная обёртка сборки изолирует вспомогательные функции преобразования
  `async/await`, которые Vite может разместить перед внутренней IIFE.
- `package-lock.json` присутствует и соответствует `package.json`.
- Чистая установка `npm ci --offline --no-audit --no-fund` в отдельную временную
  папку прошла из локального npm-кэша: установлено 195 пакетов.
- В GitHub Actions установка уже переведена на `npm ci`.

Локальная проверка выполнена на Node.js 25.4.0, npm 11.14.1.
В CI настроен Node.js 22; пользователь подтвердил зелёные задания check и deploy.
Первоначальная ошибка DNS `ENOTFOUND registry.npmjs.org` больше не блокирует
локальные проверки с установленными зависимостями и доступным кэшем.
Чистая установка из кэша не подтверждает доступ к npm registry по сети.

## Проверено пользователем на телевизоре

- Git-репозиторий создан, код отправлен в GitHub.
- GitHub Actions: задания `check` и `deploy` зелёные.
- Плагин опубликован: `https://imeg1.github.io/lmp-viewer/plugin.js`.
- Samsung QE55Q70DAUXRU, Lampa 3.3.7: кнопка и экран открываются,
  тестовый фрагмент воспроизводится.
- Возврат из плеера, повторный запуск и возврат в карточку работают.
- Стрелки и OK после возврата работают.
- В другой карточке одна кнопка и правильное название фильма.

Это результаты ручной проверки, сообщённые пользователем, а не удалённого
управления устройством. Подробности — в [чек-листе](tizen-checklist.md).

## Не выполнено

- Сценарии потери сети, недоступного URL, быстрого повторного OK и выхода
  во время подготовки на телевизоре.
- Повторное исполнение скрипта в том же окне без дублирования UI и обработчиков
  (критерий 10 ТЗ).
- Длительная проверка повторных циклов запуска и возврата.
- Звук, видимый фокус и обозначение деморежима отдельно не подтверждены.
- Точная версия Tizen и commit проверенной сборки не зафиксированы.

Критерии 5–9 ТЗ подтверждены основным сценарием. Критерий 10 остаётся открытым.
Mock-тесты не заменяют оставшиеся проверки на устройстве.

## Следующие шаги

2. Исправить обнаруженные ошибки устойчивости и повторить затронутые проверки.
3. После завершения приёмки MVP 0.1 выбрать источник для версии 0.2.

## Исправление обработки недоступного видео

Добавлен таймаут загрузки 30 секунд после Player.start, отменяемый loadeddata,
закрытием или заменой сессии. Проверен fake timers; npm run check проходит.
На телевизоре исправление ещё не проверено. Ожидание рекламного блока
до Player.start этим таймаутом не ограничивается.
