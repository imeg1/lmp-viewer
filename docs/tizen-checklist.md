# Ручная проверка Samsung Tizen

Основной сценарий подтверждён пользователем 19 октября 2026 года.

Устройство и окружение:

- Samsung QE55Q70DAUXRU;
- ПО телевизора: `T-NKM2DDEUC-0090-21 23.9` (со слов пользователя);
- Lampa: 3.3.7 (со слов пользователя); версия оболочки и ревизия веб-интерфейса
  отдельно не уточнялись;
- точная версия Tizen не установлена;
- плагин: `https://imeg1.github.io/lmp-viewer/plugin.js`;
- источник: `https://www.w3schools.com/html/mov_bbb.mp4`;
- точный commit опубликованной сборки не зафиксирован.

## Сценарии

- [ ] HTTPS-адрес `plugin.js` доступен на телевизоре.
- [x] После подключения и перезапуска Lampa открывается без ошибок.
- [x] В карточке фильма появляется ровно одна кнопка «▶ Смотреть онлайн».
- [x] Стрелками пульта можно выделить кнопку, OK открывает экран плагина.
- [x] Отображаются название выбранного фильма и явное описание деморежима.
- [x] На кнопке «▶ Воспроизвести тестовое видео» есть видимый фокус.
- [x] OK запускает фрагмент Big Buck Bunny через встроенный плеер Lampa.
- [x] Изображение и звук отдельно подтверждены проверяющим.
- [x] «Назад» из плеера возвращает на экран плагина; OK снова запускает видео.
- [x] «Назад» с экрана возвращает в карточку, стрелки и OK продолжают работать.
- [x] После нескольких повторений сценария фокус и возврат не ломаются.
- [ ] Повторная загрузка `plugin.js` в том же окне не дублирует кнопку и обработчики.
- [x] Открытие другой карточки показывает её название, не предыдущее.
- [ ] Потеря сети при запуске видео даёт понятное сообщение; после восстановления возможен повтор.
- [ ] Недоступный URL видео обрабатывается без зависания интерфейса.
- [x] Быстрое повторное OK не запускает несколько операций подготовки видео.
- [ ] Выход во время подготовки источника не приводит к запуску видео поверх другого экрана.

Для последних сценариев можно временно подменить `DemoSource` на отклонённый
или задержанный Promise в локальной диагностической сборке. После проверки
вернуть исходный источник и пересобрать плагин.

Результат: дата, проверяющий, пройденные пункты, описание ошибок.
Автоматические mock-тесты не заменяют этот чек-лист.

Наблюдения: перед видео показывается реклама Lampa. Предыдущий URL Google
Cloud Storage возвращал AccessDenied; после замены источника видео работает.

Потеря сети: пользователь сообщил, что ошибка не появляется, но «Назад» работает.
Добавлен таймаут 30 секунд от Player.start до loadeddata, после рекламного блока.
Показ ошибки после обновления и повторный запуск после восстановления сети
требуют повторной проверки на телевизоре. Таймаут не ограничивает ожидание
внутри рекламного модуля до Player.start.
