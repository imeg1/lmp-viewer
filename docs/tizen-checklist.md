# Ручная проверка Samsung Tizen

Ни один пункт пока не подтверждён на телевизоре.

Записать перед проверкой:

- модель и год телевизора, версия Tizen;
- приложение Lampa: v1.13.5;
- адрес веб-интерфейса и `Lampa.Manifest.app_version`;
- URL `plugin.js` и дата сборки.

## Сценарии

- [ ] HTTPS-адрес `plugin.js` доступен на телевизоре.
- [ ] После подключения и перезапуска Lampa открывается без ошибок.
- [ ] В карточке фильма появляется ровно одна кнопка «▶ Смотреть онлайн».
- [ ] Стрелками пульта можно выделить кнопку, OK открывает экран плагина.
- [ ] Отображаются название выбранного фильма и явное описание деморежима.
- [ ] На кнопке «▶ Воспроизвести тестовое видео» есть видимый фокус.
- [ ] OK запускает Big Buck Bunny через встроенный плеер Lampa, есть изображение и звук.
- [ ] «Назад» из плеера возвращает на экран плагина; OK снова запускает видео.
- [ ] «Назад» с экрана возвращает в карточку, стрелки и OK продолжают работать.
- [ ] После нескольких повторений сценария фокус и возврат не ломаются.
- [ ] Повторная загрузка `plugin.js` в том же окне не дублирует кнопку и обработчики.
- [ ] Открытие другой карточки показывает её название, не предыдущее.
- [ ] Потеря сети при запуске видео даёт понятное сообщение; после восстановления возможен повтор.
- [ ] Недоступный URL видео обрабатывается без зависания интерфейса.
- [ ] Быстрое повторное OK не запускает несколько операций подготовки видео.
- [ ] Выход во время подготовки источника не приводит к запуску видео поверх другого экрана.

Для последних сценариев можно временно подменить `DemoSource` на отклонённый
или задержанный Promise в локальной диагностической сборке. После проверки
вернуть исходный источник и пересобрать плагин.

Результат: дата, проверяющий, пройденные пункты, описание ошибок.
Автоматические mock-тесты не заменяют этот чек-лист.
